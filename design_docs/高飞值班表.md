# 高飞值班状态表

## 总则

### 基本工作信息
- **工作时间**：7:30-18:00
- **日常节奏**：早上布置（点檀香、开药罐盖散味、摆古方手抄本）→ 上午站柜台接诊 → 下午拉帘磨药（后屋，2小时装三四百粒）→ 傍晚收拾关门
- **工资**：1500/月

### 风险区域规则
| 高飞位置 | 翻墙风险 | 原因 |
|----------|---------|------|
| 一楼前台 | **低** | 翻墙路线绕过一楼（后院→铁皮门→二楼楼梯），前台听不到后院动静 |
| 后屋磨药 | **高** | 后屋紧邻后院门和楼梯入口，磨药时安静，任何铁门响/楼梯响都能听到 |
| 后院倒垃圾/晾药材 | **极高** | 直接在翻墙路线上，面对面 |
| 不在（外出/休假/婚礼） | **零** | 无人 |

### 策反分界线
- **策反条件**：D4-D5四条攻略路线（道德≥2/见微≥3/坚毅≥3/博学≥3）任一突破中层信息后，高飞态度转变
- **标志**：高飞从"WSP的人"变成"可以信任的内应"
- 策反前=风险源（听到动静→告诉WSP），策反后=助力（开门/放风/告知WSP行踪）

## 翻墙系统交叉影响（核心）

### 遭遇情景一：后院翻墙时高飞在后屋磨药

**触发条件**：D1-D5任意下午（13:00-17:00），D6默认路线

**未策反**：
1. 你翻墙进后院→铁皮门嘎吱响（坚毅<2）or安静进入（坚毅≥2）
2. 响动时→高飞放下药杵，拉开帘子探头："谁？"
3. 看到后院有人→高飞的反应：
   - 如果认出你（来过诊所2次以上）："你怎么从后面来了？"→你可以编理由
   - 如果不认出（第一次来）："你是谁？这是我们诊所后院！"→紧张
4. **关键**：高飞当晚会告诉WSP——"今天有人从后院进来了"
   - WSP的反应：根据变体状态（恐慌收紧/动摇加速/不知情）
5. 如果你上了二楼被高飞发现→更严重："你上楼干什么？！那是王哥的家！"

**已策反**：
1. 你翻墙进后院→铁皮门可能没锁（高飞故意的）
2. 高飞在后屋→听到动静→假装没听到，继续磨药
3. 你经过后屋时高飞可能小声说一句："楼上没人。" or "王哥出去了。"
4. 你搜完下楼→高飞递给你一杯水："渴不渴？"→若无其事
5. **不会告诉WSP**

### 遭遇情景二：二楼搜查时高飞上楼

**触发条件**：D1-D5任意时段，高飞需要上楼送药/找东西/被WSP叫上去

**未策反**：
1. 你在二楼搜查→听到楼梯响（高飞上来取药材/送东西给WSP）
2. 你必须藏起来（书房/衣柜）或面对他
3. 高飞进二楼→发现异常（门开着/东西被翻过）：
   - 没看到你："嗯？门怎么开着……"→检查一圈→下去→可能告诉WSP
   - 看到你：愣住→"你……你在这干什么？"→反应取决于之前关系深度
4. **高飞上楼的频率**：下午2-3次（取药材、送煎好的药引给WSP、关二楼窗户）

**已策反**：
1. 高飞上楼前会故意弄出响动（咳嗽/大声关门）→给你信号
2. 如果必须上楼→会先喊一声"王哥，我上来拿个东西！"→给你反应时间
3. 看到你在二楼→假装没看见→拿了东西就走

### 遭遇情景三：前台闲聊后偷溜后屋

**触发条件**：玩家先去诊所前台找高飞聊天，然后趁机溜到后屋/后院

**未策反**：
1. 你在前台和高飞聊天→借口去"厕所"/"看看后面"
2. 高飞：正常指路——"厕所在后面。"但会注意你去了多久
3. 你超过5分钟没回来→高飞起疑→去后面找你
4. 如果你已经进了后院/上了楼→被高飞从后屋布帘后撞见
5. 高飞："你不是去上厕所吗？怎么在这？"→你需要编理由或摊牌

**已策反**：
1. 你在前台暗示："我想去后面看看。"
2. 高飞明白→点头→"厕所在后面，慢慢来。"→不跟过去
3. 如果有人（WSP/患者）问你去哪了→高飞帮你圆："他上厕所去了。"

### C线特殊：WSP视角下高飞是威胁

在C线（玩家操控WSP）中，高飞的存在完全翻转：
- **高飞知道太多了**——假药流程、进货、内外两本账
- WSP每天都在想："他会不会有一天说出去？"
- C线的紧张感来自"高飞是我最大的不确定因素"
- **变体E时WSP让高飞"放假"的真实理由**：不是因为好心，是因为怕

## 策反后的主动助力

被策反后（D4-D5中层信息突破），高飞从风险源变为以下助力：

### 1. 行踪情报
- "王哥今天出去了，说下午才回。"
- "王哥在前面看诊呢，现在后面没人。"
- "小燕去她妈家了，楼上就王哥一个。"
- D6变体D："王哥去了派出所。带着一个袋子。"

### 2. 后门控制
- "我今天忘了锁后门。"（故意不锁）
- 铁皮门平时从里面插着→高飞可以"忘记"插
- 但如果WSP发现门没锁→会问高飞→"门怎么没锁？"→高飞："啊，我忘了……"
- **风险**：用太多次WSP会起疑

### 3. 放风
- 你在二楼搜查时，高飞在楼下
- WSP如果要上楼→高飞："王哥，那个……刚才有个人找你看病。"→拖住WSP
- 有人来后院方向→高飞咳嗽两声（约定信号）
- **前提**：你和高飞事先约好信号

### 4. D6主动找你
- 条件：D4-D5被策反 + D6到来
- 高飞主动找玩家（A线去修车铺/B线去派出所）
- 说出隐藏信息："有件事我也不知道是不是想多了……"（WYP目击事件）
- 这是双胞胎第四条隐藏线索通道的**主动触发版**

### 5. D7证词
- 如果D7进入最终对决阶段
- 高飞可以提供：
  - 假药制作流程证词
  - WYP目击证词（"我见过一个长得一样但不是他的人"）
  - 进货单/内账位置
