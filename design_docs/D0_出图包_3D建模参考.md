## 〇、总则（所有提示词共用约定）

- **年代基调**：2005 年前后东北后工业小镇，下岗潮后，衰败与怀旧并存。
- **色调**：整体低饱和。灰蓝 + 暖黄为主；夜晚深蓝 + 暖橙灯光；医疗绿点缀（呼吸机/监护仪）。
- **D0 时间线**：单日。董点事 14:00 归乡 → 16:00 街道 → 18:00 便利店 → 20:00 葬礼晚饭；李正为当日**清晨**噩梦醒来 + 上午县局动员会 + 班车回镇；王少鹏为当日 14:00 诊所午后。所以 D0 出图以**白天 / 傍晚 / 夜晚 + 清晨**为主，**无雾**（雾从 D2 才起）。
- **视角约定（关键，区别于旧版等距图）**：
  - 场景 = `3D game environment, eye-level three-quarter perspective` 或 `wide establishing shot`，强调可读几何、模块化、PBR，给建模师当参考，而**非** isometric。
  - P0 场景额外附一条 **blockout 俯视布局图** 提示词（`orthographic top-down floor plan`），给关卡搭建定空间关系。
  - 物件 = `orthographic three views (front / side / back), neutral grey studio background, 3D asset reference sheet, PBR`，给建模直接照着做。
- **共用后缀**：
  - 场景氛围图：`--ar 16:9 --s 250 --v 6.1`（低 stylize 保结构准确）
  - 场景 blockout：`--ar 1:1 --s 50 --v 6.1`
  - 物件三视图：`--ar 3:2 --s 100 --v 6.1`
- **负面提示（建模图通用，按需加）**：`--no text, watermark, signature, people, characters, anime, cartoon outline`
