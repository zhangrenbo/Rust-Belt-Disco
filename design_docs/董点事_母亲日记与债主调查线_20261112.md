# 《东北迪斯科》董点事线：母亲日记、蓝色旧楼与债主调查

> 整理日期：2026-11-12
> 性质：对话设计纪要 + 首轮可执行剧情规格。标有【已确认】的是本次讨论明确认可的方向；【待定】为尚未确定的细节；【草案】为便于讨论而补写的表现，不视为正式剧本。
> 本文只涉及新版董点事路线。旧 Unity 工程归档不等于旧世界观作废。当前正式 HTML 开场仍是 5×4 纸箱滑块，取得箱底纸包后尚未接好正式后续剧情。

## 一、叙事原则【已确认】

- 游戏仍以董点事调查母亲遇害、寻找杀人者为核心。凶手象征随机降临的恶，不为了合理化谋杀而强行安排母亲得罪人、掌握秘密或钢铁厂阴谋。
- 董点事带着愤怒追查，却不断追问母亲是否得罪过谁，乃至是不是亲近的人或自己做错了什么。故事的讽刺来自受害者家属为无理由的恶寻找理由。
- 调查不能只是 NPC 发任务或点击物品领地址；玩家应借由母亲留下的真实生活记录、建筑特征、空间辨认和知情者谈话主动推进。
- 小镇和人物会随时间改变。债主当年的风光与今天的困顿构成“时过境迁”的情感反差；不能把他写成特意藏身或突然洗白的工具人。
- 父亲的可疑性是后段才可能到达的情绪高点，不在这条开局债务支线中提前指向父亲。
- 目前对话中游戏时间周期最新讨论改为 **14 天**，但不把每条任务强行锁死到某一天；本支线以“第一天取得线索、后续（可能第二天）找到债主”为设计节奏，而非必须等到 Day 2 才触发。
- 旧稿存在便利店、父亲葬礼、叔叔家、修车店等事件，不能未经重新编排就当成新版 Day 1 已实现剧情。

## 二、债主的人物经历【已确认】

1. 债主原本也是工厂下岗职工；下岗后做一点小生意，一度赚到钱，才有经济能力借钱给董点事的母亲。
2. 当年他比母亲宽裕，衣着体面，对香港充满向往，觉得那里是自由的土地；楼房外观体现他当时的审美和心气。
3. 他确实去过香港，**后来又回到这座小镇**。玩家可能误以为他去了香港再也没有回来，这是需要被后续证言纠正的假设。
4. 他并未刻意隐姓埋名或逃避追查，只是早已搬离旧居。镇上一些认识他的人知道他现在住在哪儿。
5. 多年以后，他的生活已穷困潦倒，和母亲日记里“做生意赚了钱、日子好起来”的形象形成反差。
6. 玩家原本怀疑他可能因催债杀害母亲，找到时却看见一个同样被现实与岁月磨损的可怜人。这里要克制、生活化，不靠哭诉说教；他可以有缺点、当年也可能发生过争执，但矛盾不等于杀人。
7. 债主最终会给董点事一条**可以核实、通往下一调查对象的线索**。【待定】究竟是什么事、指向谁、如何与其他证据验证；不能擅自定成“又一个跟母亲吵架的人”或直接交付下一个任务坐标。
8. 【待定】债主姓名、年纪、具体做什么生意、何时去港又返乡、发迹与衰落的具体原因、现住处、家庭成员、是否追过债、是否有可靠不在场证明。这些均不得当作已确认事实。
9. 债主今天落魄**不应无依据地归因于母亲欠款未还**。

## 三、开场遗物：一本烧焦的母亲日记【已确认】

- 新版现行开场：便利店 5×4 纸箱滑块。玩家移出七件旧物，找到并拾取纸箱底部的纸包。纸包内作为后续剧情提案放置 **母亲日记**，而不是最终采用先前“账本+四位密码铁皮盒”的方案。
- 日记为母亲自己写的普通生活记录，不是故意留给玩家的密文、谜题或藏宝图；部分内容受火烧损，尤其债主**姓名必定烧毁不可直接阅读**。
- 母亲记载：那天找一位下岗后靠小买卖赚钱的人借了钱；见面时注意到对方穿着什么衣服；对方住在一栋外墙刷了**非常鲜明的蓝色油漆**的楼里；**一楼有多幅香港电影海报式墙绘／涂鸦**；她对这栋楼与小镇其他灰扑扑房屋截然不同的外观产生感慨。
- 日记自然提及债主喜欢香港电影、向往香港，把香港视作自由、做生意有奔头的地方；这是其人生状态与性格的表达，不是为了玩家留下的提示。
- 读完日记要能形成调查意图：“去镇上找那栋特别的蓝楼”，而不是凭空获得姓名／完整地址。
- 【待定】衣服的具体颜色和款式、借款数额、具体日期、母亲用词、街道和门牌剩余多少、墙绘是哪几部影片、日记其他页内容。此前提过“棕色皮夹克”“两万元”等属于示例，不应先写死。
- 【待定】烧毁的部位必须做逐字排版稿；首要硬约束是姓名看不到、具体地址不能直接解答，建筑外观和香港电影墙绘足够明确。

### 日记文案意向【草案，不是最终原文】

> 今天去找了［姓名处纸张烧毁］借钱。他下岗以后做点小买卖，没想到真挣了钱，看着比以前精神。今天他穿了［具体衣着待定］。他住的楼外头刷得特别蓝，跟镇里那些灰楼一点也不一样；一楼还有几幅香港电影海报，花花绿绿。他说喜欢香港，觉得那里自由，做买卖有奔头。我也没去过，不晓得是不是他说的那样。这次跟他借了［金额待定］，希望早点还上。

写作要求：口吻是普通母亲的生活感慨，不是“债主特征清单”；尤其不要写成她为了防备犯罪特意记录相貌或地址。

## 四、可实际游玩的流程与状态

### 节点 A：纸箱与日记（预计第一天）

1. 进入便利店开场，完成已实现的 5×4 滑块，把旧物依次挪出。
2. 点击箱底纸包，展开后取得烧损的母亲日记【后续尚未实现】。
3. 在可翻阅的日记界面读到借钱经历、债主曾做小生意、衣着、蓝色楼房与香港电影墙绘；姓名被烧掉，具体地址不可辨。
4. 任务记录：**“寻找母亲当年的债主”**；当前提示可使用 **“在小镇里找出母亲日记里那栋特别的房子”**。不直接标出目标建筑的地图箭头。
5. 状态候选：`diary_found`、`blue_building_clue_known`。

### 节点 B：凭建筑外观在镇里找房子（预计第一天或玩家自行安排的时间）

1. 场景在原本的小镇里存在，并不是任务解锁后才生成。
2. 目标建筑：外墙曾刷过**非常醒目的蓝漆**，一楼绘有**数幅香港电影海报式画作**；其蓝色和周围灰色工业住宅强烈对比。多年后墙面可有褪色、剥落、覆盖痕迹，但足以凭日记辨认。
3. 玩家自由步行探索，不直接获得住址与自动导航。进入蓝楼附近的预设触发区域、且已读过日记时，**只触发一次**董点事的自言自语。
4. 自言自语草案：
   - 董点事：“蓝色外墙……一楼还有这些香港电影的画。看样子就是我妈日记里提的地方。”
   - 董点事：“去问问附近的人吧，说不定有人记得以前住这儿的是谁。”
5. 任务更新为 **“向附近居民打听这栋楼以前的主人”**。状态候选：`blue_building_recognized`、`ask_neighbors_unlocked`。
6. 如果玩家在读日记前就发现了蓝楼，不显示识别成功的台词；之后拿到信息再来可以触发。要避免每次路过重复弹话。

### 节点 C：关于香港的自然误判与旧居易主

1. 玩家和楼周围的人交谈，得知原屋主已经**搬家**，原来那套住所不再是他的现住处。
2. 因为楼上香港电影墙绘，加上母亲日记里的香港憧憬，玩家**可以自然提出**：“他是不是已经去香港了？”——这是玩家的**猜测**，不是剧情强塞的真相。
3. 实际事实是：此人**的确去过香港，也的确回到了镇上**。现住户是否知道其完整赴港经历【待定】，不要错误写成“他从来没去过香港”。
4. 不同知情者可掌握不同的信息：新住户能说明旧居易主；老街坊了解其昔日经商或赴港经历；熟人知道他返乡后现在住的地方。【待定】具体 NPC 身份、数量、位置、说辞。
5. 核心推理关系：**港片墙绘与母亲的记述→玩家推想去香港→交谈纠正为去了又回来→确认现在仍在镇上→从真正认识债主的人口中获知现住处。**
6. 不强制采用旧维修单、摊位图、市场管理员、门卫等此前临时添加的跑腿关卡；这些此前都是建议，未经用户确认。

### 节点 D：找到债主（第二天作为目标节奏，不必硬锁）

1. 玩家根据镇上的知情者获取足够信息，找到债主现在住的地方；对比昔日蓝楼与如今的困顿居所。
2. 初见时董点事因母亲借债和遇害而愤怒，可能会质问他是否曾追债、是否与母亲的死亡有关。
3. 玩家从住宅、生活细节与谈话里逐渐意识到：当年做生意风光的人，如今也很落魄。表达重在生活处境的反差，不用 NPC 自述一篇悲惨史。
4. 债主交代或确认昔日和母亲的借款关系，并给出**可进一步验证的下一条线索**。具体内容待设计；不要自动证明他清白，也不应不经证据就把他定为凶手。
5. 状态候选：`creditor_identified`、`creditor_found`、`creditor_testimony_recorded`、`next_lead_available`。条件应根据剧情验证结果再确定。

## 五、场景与程序实现边界

- **已存在的正式内容**：HTML 纸箱谜题、旧物移出、纸包拾取、自动存档。
- **需要制作**：纸包打开与日记查看、烧毁版日记图层、调查任务文本、蓝色楼房及一楼香港电影墙绘、区域触发器、附近居民对话、赴港／返乡／搬迁信息链、债主现居场景及对话、后续线索衔接。
- 场景按项目当前 2.5D 设计原则组织，建筑应该在视觉上可辨认，但地理关系、触发碰撞区域尺寸和相机参数需在关卡制作时测量，不擅自声称已经实现。
- 建筑外墙“特别蓝”和一楼香港电影海报是**明确设计内容**，不替换成无关的石狮子、红鲤鱼、普通涂鸦等未确认元素。
- 用户希望 **谜题自然产生于人物生活和环境**；不采用四季度结余算四位锁、重复金额、硬造密码、把多个电话尾号凑在一起等此前被否定或未确认的设计。

## 六、下一轮尚须明确的问题

1. 日记页的正式全文与烧毁遮挡排版：保留哪些字、实际借款数额、对方衣着细节。
2. 蓝楼在镇上的实际位置、和周围建筑的对比，以及香港电影画面是否引用真实电影海报（制作时考虑授权或采用原创致敬式图像）。
3. 区域触发后可问的居民具体是谁，他们分别知道哪一层事实；怎样通过谈话明确得出债主已返乡和现住处。
4. 债主赴港又回来的经历、经济为何再度衰落、现在的生活状态，避免用未经设定的故事解释。
5. 债主给出的**下一条可验证证据**和它所指向的下一个人物／地点；与母亲遇害案证据链的关系。
6. 14 天整体进度与 NPC 日程：不强制第一天必须结束在哪个房间，第二天必须见到谁，允许玩家探索先后不同。

## 七、重要防误读说明

- 本文是 **剧情设计纪要**，不是“已开发实现”的宣告。
- 本次讨论最后明确的版本优先于早期助理提出的账本／密码锁／老周／旧市场跑腿草案。
- 已确认的是“**烧焦日记—蓝楼港片墙绘—误以为去了香港—确认返镇但已搬家—老熟人引路—见到落魄债主—获得下一线索**”的因果链；没有确认的人名、数字、NPC 台词和场景细节不得被当成正史。
