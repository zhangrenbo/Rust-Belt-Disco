# 《东北迪斯科》新版剧情：债主—追求者—照片—李正与十四日倒计时

> 版本继承规则：新版与旧版不冲突的设定可以继续沿用；发生明确冲突时，以新版为准。旧 INK 中的场景、台词与分支仅作可继承素材，不自动覆盖本文件。

## 一、全局设定：十四日倒计时（已确认）

- 玩家调查母亲遇害案的故事时间跨度为 **两周（14天）**。
- 两周后，母亲留下的便利店将被出售给别人，并被新的建筑取代；旧店作为承载母亲回忆的空间会消失。
- 这使调查具有不可逆的现实期限：玩家希望在最后的十四天里查明凶手，而不只是无限期地寻找答案。
- 叙事主旨：玩家寻找杀害母亲的人，同时面对与母亲有关的最后一处物理记忆即将消失。
- **待细化**：买方及成交安排、是否存在延迟/阻止转让的途径、最终日的具体结算、没有找到凶手时的不同结局。不要将这些尚未确认的内容写死。
- 注意：旧版有关地产收购的设定如不冲突可复用；如果旧版时间线或交易方式与十四日必然售出冲突，服从此处新版设定。

## 二、新版第一天任务与探索（已确认）

- 新版以寻找杀害母亲的真凶为长期主线；现阶段当天明确调查目标是寻找和母亲债务有关的人（下文称“债主”）。
- 叔叔说自己需要去修车店上班，暂时无法陪同调查。
- “帮叔叔干活”**删除作为第一天主线并列路线的设计**，改为自由探索中的可选事件：如果玩家主动来到叔叔的修车店，叔叔会说“来都来了，帮我做点事吧”一类的话，玩家可以选择帮忙或继续调查。
- 保留旧版中不冲突的关系、时间消耗、后续反应机制是可选方向，不应因此令主线被强制中止。
- 玩家如果调查顺利，可以在第一天就找到并见到债主；如果绕路或探索支线，也能在之后继续调查。
- 在第一天见到债主并取得新线索后，**允许当日立即继续追下一条线索**，没有“必须等第二天”的硬性章节锁。
- 债主可有自己的活动安排；这属于建议的实现方案，具体地点和时段尚未敲定。

## 三、第一嫌疑人：与母亲债务相关的人（已确认的方向）

- 玩家从母亲遗物、账目、债务相关记录调查到此人；因债务纠纷、利益与报复动机而产生最初怀疑。
- 已讨论过的“蓝色建筑”“香港误导、实际回镇”等找人路径，可作为相关线索设计的基础；具体物证、地点与顺序以之后的新版细化稿为准。
- 债主的关键叙事功能不是简单自证清白，而是提供下一条调查入口：**母亲当年曾被一个男人长期追求**。
- 债主可能描述对方频繁出入便利店、曾提出替母亲偿债、后来两人闹翻；这些是拟采用的对话细节，尚可修改。
- 玩家由此从“金钱纠纷导致谋杀”转而怀疑“求爱受挫导致情杀”。

## 四、第二嫌疑人：母亲当年的追求者

### 已确认的角色定位

- 玩家小时候**不认识**这个男人；他不是一出场便可直接访问的熟人，需要玩家依据他人的零散回忆自行查找。
- 他当年长期追求玩家母亲；他曾经给母亲拍过照片，因此掌握有价值的老照片。
- 玩家会合理怀疑他与情杀有关，但这仍然是玩家的假设，**不等于确认他是真凶**。
- 追求者与债主是两种不同怀疑：前者涉及感情、拒绝、占有与关系边界，后者涉及经济利益。

### 已提出且用户认可的人设方案（可继续细化）

- 暂名 **周建国**；名字未最终锁定。
- 如今约四五十岁，在镇上经营一家衰落的照相馆；年轻时在钢铁厂做宣传相关工作，下岗后以婚纱照、证件照、遗像拍摄谋生。
- 性格内向、寡言、表面客气，镇上人对他评价不一。
- 父母离婚后，他常来便利店买东西、帮母亲干活，追求多年未得回应。自认为在照顾母亲，但母亲可能感到被纠缠。
- 可能存在情书、母亲要求他别再来、遇害前发生争执等可调查证据；这些应由玩家查证，而不是靠单人叙述直接定案。
- “母亲或许仍放不下父亲”可以作为情感反转方向，**不能在此直接揭露或证实父亲涉案**。
- 即使追求者不是凶手，也不应把越界纠缠自动洗白为深情。

## 五、关键物证：晴天撑伞的人（照片线）（已确认）

- 第二嫌疑人曾给母亲拍照，因此持有一张（或一组）旧照片。
- 玩家在与他交谈时，需通过适合的能力**检定**，或者选择正确的对话选项，才能获得关键照片；两条路径至少允许其一成功。
- **照片中的重点**：便利店附近出现一个非常可疑的人；**天气晴朗，此人却撑着伞，在便利店周围来回走动**。
- 用户已确认“晴天撑伞、在便利店周围徘徊”的画面事实。是否在多张照片里反复出现、外貌是否清楚、为何撑伞、拍摄日期、此人身份，均未定。
- 不要以“照片里日期与账本矛盾”取代该核心线索；此前提出过的日期矛盾只是被后续明确方案覆盖的早期建议。
- 玩家应能保存照片作为实物证据，可在之后的调查和对话中再次出示。
- 得到照片本身可以合理推导“当年有人在观察或监视便利店”，但不自动证明晴天撑伞者就是凶手。

## 六、照片之后：寻找李正（已确认）

- **获得照片后，玩家的下一步调查方向是去找李正。**
- 李正正是当年侦办玩家母亲遇害案的刑警，与旧案有直接关系。
- 玩家向他展示照片，尝试联系旧案侦查信息与照片中的陌生人。
- 李正对照片具体说什么、是否曾见过伞下的人、旧案里已有何记录、能提供什么新线索，**待设计**。不得擅自写成已确认事实。
- 设计意图：让“债主口述 → 追求者的私人旧照 → 李正的正式侦查视角”形成相互验证、层层推进的调查链。

## 七、嫌疑递进的哲学结构（已确认的整体方向）

- 第一阶段：怀疑债主因钱财与报复杀人。
- 第二阶段：怀疑母亲的陌生追求者因感情纠葛杀人。
- 后续仍需更多嫌疑对象与线索，怀疑程度应从外部社会关系逐渐深入玩家的家庭和信任。
- 最后玩家甚至可能怀疑**已经死去的父亲**与母亲的死亡有关；这是计划中的终极讽刺与心理震动，**不是父亲为真凶的定论**。
- 母亲遇害的历史事实不应因为玩家选择而任意改变；玩家行动可以改变遇到谁、何时知道什么、建立或伤害哪些关系，以及对证据的解释。
- 关键调查线索由事件与证据链触发，不将嫌疑人的登场硬锁在某一天。玩家可以调查得比默认进度更快。
