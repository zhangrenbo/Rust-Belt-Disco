# 东北迪斯科 · Rust Belt Disco

当前主项目使用 HTML、CSS、JavaScript 和 Vite，已替代旧 Unity 工程。游戏源码、运行素材、剧情原稿、策划资料和美术制作记录集中保存在本仓库。

## 启动

需要 Node.js 22.12 或更高版本：

```sh
npm ci
npm run dev
```

访问 http://127.0.0.1:5173/ 。Windows 也可双击 `启动游戏.cmd`。`启动工作台.cmd` 依赖开发者本机安装的共享工作台；其他电脑使用上述 npm 命令即可。不要直接用 file:// 打开 index.html。

## 当前玩法

新游戏选择董点事后，进入便利店的 5×4 纸箱滑块开场：拖动或使用方向键移动旧物，将其移到右侧中间两格缺口，再移出纸箱。清空旧物后，点击箱底纸包拾取。支持撤销、重摆、返回菜单和自动续玩。

纸包具体内容及后续剧情尚待设计，当前没有接回旧公交车站。旧物为本地 SVG 占位素材，尚非最终美术。李正、王少鹏路线尚未开放。主菜单和设置支持中英文 UI，剧情正文仍为中文。

纸箱进度使用独立自动存档；继续游戏优先恢复纸箱进度。历史公交站及其手动存档保留兼容。所有进度保存在当前浏览器、当前地址的 localStorage，Unity 存档不互通。

## 策划与项目目录

| 路径 | 内容 |
| --- | --- |
| `index.html`、`app.css`、`scene.js` | 正式入口与界面 |
| `src/box/` | 现行纸箱开场 |
| `src/station/` | 历史车站剧情及存档兼容 |
| `src/core/` | 导航、语言、音效等共享逻辑 |
| `public/` | 游戏运行素材 |
| `content/story/ink/` | INK 剧情原稿与背景设定 |
| `content/story/source-documents/` | 原始 Word、XMind、Markdown 策划及剧本 |
| `content/story/legacy-data/` | 迁移保留的剧情数据 |
| `design_docs/` | 场景结构、扩写、动画管线与设计笔记 |
| `美术概念/` | 美术参考、提示词、生成记录及候选 |
| `建筑参考/`、`UI参考/` | 建筑与原始界面参考 |
| `content/art/` | 美术来源清单和历史素材 |
| `docs/` | 制作说明、迁移清单、验证报告 |
| `scripts/`、`tools/`、`tests/` | 开发工具、回归脚本与测试 |
| `归档/` | 替换前的完整 Unity 仓库快照 |

策划、提示词和历史生成记录不代表玩法已经实现或候选美术已获批准。现行开场以纸箱实现及其最新说明为准，旧 A000 公交站文本仅作历史内容。

## 检查与构建

```sh
npm test
npm run build
```

构建输出为 `dist/`；`npm run preview` 可预览构建。`npm run verify:content` 对照历史迁移清单检查素材与资源路径；原稿后续编辑可能造成旧哈希不一致，具体结果见 [迁移记录](docs/Git仓库迁移_20261107.md)。
