# 东北迪斯科 · 场景机位校准

## 现有问题

前 40 景和补充 20 景的文本提示都写了“45° 正交俯视”，但批次只核验了提交回执，没有逐张核验成图。用户已指出大量画面机位不一致。全部 60 景保留为历史候选，逐景复核前不能视为可用游戏背景。

## 固定机位

- 画幅：16:9。
- 相机：向下 45°，正交投影；同一场景系列保持同一水平旋转方向。
- 画面：无地平线；地面同一方向的线始终平行；远近相同物件保持同一像素尺度；垂直物件不向消失点倾斜。
- 室内：移除屋顶及靠相机的墙，保留可走地面，但不能改成正面室内摄影。
- 对照：`public/media/station-night.png` 为游戏现有车站构图，`美术概念/固定机位_正交45度_场景构图参考.png` 为程序绘制的正交投影块面；后者是待验证的几何参考，不是已获用户认可的美术素材。

## 单景试验

先选择一幅外景和一幅室内，分别用对应的固定机位布局图作为 **Image Prompt**，而非 Style Reference。候选参数为 `--ar 16:9 --raw --v 8.1 --iw 2 --s 0`；保留场景所需的冬季、光线和建筑描述，但去掉含糊的 `diagonal view`。`--iw 2` 和 `--s 0` 是待测值，不能当作机位已锁定。Midjourney 官方说明 Image Prompt 影响构图而不精确复制图像；`--iw` 的 V8.1 范围是 0–3，低 stylize 可减少自由发挥。

对每组实际四张图逐张记录：视角、平行线、物件尺度、入口连通和能否融入现有游戏。只有机位通过的单景才进入后续场景试验；批量提交脚本的 `camera_calibration.visual_pass` 保持 `false`，直到有真实视觉核验记录。

## 当前检查阻碍

工作 Chrome 的隐藏任务页可以提交任务并读取回执；Organize 页也能列出补充场景的候选，但从隐藏页打开单张图片后，`Download Image` 原生控件仍未加载。Organize 的“Select all”会一次选中约 132 张，超出单景校准所需。按项目的后台浏览和原生图片下载规则，不能通过前台切换或自制图片传输绕过。需要获得可在后台原生下载单张的站内路径，或取得用户提供的实际错误成图，才能完成逐张视觉核验。本次没有提交新的机位校准生成任务。
