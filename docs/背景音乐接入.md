## 播放行为

- `src/core/music.js` 在页面初始化时立即创建并恢复 AudioContext，加载对应曲目，不再主动等待点击。工作台所用 Electron 的默认策略允许自动播放；普通 Chrome 如拦截无交互页面，保留首次真实点击或按键恢复播放。已保存的音乐音量为 0 时仍静音。
- 解码后的音频缓存在本次页面会话中，以 AudioBufferSourceNode 循环；切到车站或返回主菜单交叉淡入淡出 1.2 秒。快速切换最多保留一条正在退出的旧音乐，防止重叠堆积。
- 存档、设置及其他资料页延续进入前的配乐。打开正式剧情对话时音乐降到当前音量的 65%，收起后恢复。
- “音乐音量”在点击“应用设置”时生效，与原设置保存方式一致；0 立即静音，解除静音平滑恢复。语音和音效滑条继续保留，本次没有增加配音或交互音效。
- 隐藏页面或离开页面时暂停 AudioContext；回来时延续当前循环。加载新曲失败时保留原曲并显示提示，下一次操作可重试。

代码入口：`scene.js` 安装播放器，现有 `disco:view-change`、`disco:audio-settings` 事件负责切换与音量应用。未更改 UI PNG 和游戏存档格式。
