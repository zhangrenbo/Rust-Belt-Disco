# 人物档案：复用已有书册 UI

## 当前：纯人物档案与书页后方纸签（2026-09-14）

用户明确要求这是一款解谜探案游戏，人物页只写档案。右页现仅保留姓名、身份、出场地点和人物简介；已移除全部战斗数值、等级、经验、货币和加点按钮。`src/core/dossier-characters.js` 删除了演示属性和加点逻辑，切换人物只更新档案、真实头像及无障碍标签。

四张角色纸条置于原书页后、背景前。书册以同一完整 PNG 在原位绘制前景遮挡层，原纸页与边缘遮住纸签根部，露出的姓名可点击；左上返回沿用完整独立破边纸条。没有生成或修改 PNG，没有更换原书册或改动 UI参考。

现有资料支持董点事、李正、王少鹏三位的实际头像和档案切换；第四签保留“待确认”，已询问但尚未收到指定。身份及开场地点来自既有 D0/D1 资料。可玩内容继续暂停，浏览不写存档，返回、Esc、键盘切换、设置草稿和静音保留。

15项现有测试、172个迁移哈希、67个资源路径与构建通过。`scripts/qa-personnel-cdp.py` 使用固定工作 Google Chrome + 直接 CDP，在独立后台页以隔离内存存储验证18项操作；1440×810三位角色及844×475画面已目视检查。当前证据为 `personnel-record-verification.json` 和 `personnel-record-*.png`，美术待用户验收。

以下是接入历史，其中旧数值面板和纸条位于书页上方的版本已经撤下。

## 历史：纸条按钮与中文文字排版

按用户要求，左上返回与右侧四签均复用 `entry-title-slip-v2.png` 的破边纸条，角色姓名横排，选中使用暗红墨字与轻微外移。右页在原书册内排姓名、身份、等级经验、五行中文属性和人物简述；中文使用楷体，数字使用 Georgia 并右对齐。两张属性操作纸牌复用 `settings-reset-button-v1.png`。原书册与头像保留。

角色切换同步更新身份与简述；简述仅使用已有 D0/D1 开场资料，第四位身份尚未指定。设计方案及审查在 `人物档案纸条与排版设计.md`；当前页面检查使用 `scripts/qa-personnel-cdp.py --paper`，证据写入 `personnel-paper-verification.json`，四张截图为 `personnel-paper-*.png`。当前可玩内容继续暂停，属性数值仍为 UI 演示，未增加新玩法。

## 历史：侧签改为角色切换

用户要求四个侧签对应四位角色，点击后真正更换头像。现在由 `src/core/dossier-characters.js` 驱动原书册，姓名、头像、选中侧签和属性纸面的无障碍标签同步更新；上下方向键、Home、End 也可切换。原等级和属性仍为 UI 示例，演示升级数值按角色独立放在内存，不写入存档。

已接入董点事、李正、王少鹏。董点事使用现有 `public/media/characters/dong-reference.png` 与原独立相框；李正复用原头像；王少鹏使用 `content/art/legacy-png/T_C003_王少鹏头像.png` 的原样副本 `public/assets/dossier-wang-shaopeng.png`。没有生成新头像或更换书册底图。

第四位角色尚未由用户指定，已经询问；第四签暂为禁用的“待确认”。当前是三位可切换，不能视为四位需求已完成。新增15项实际 Chrome + 直接 CDP 检查与4张截图见 `personnel-characters-verification.json`，其中 `allFourConfigured` 为 false。15项项目测试、172个迁移哈希和62个资源路径通过。当前纯 UI 展示状态保留，可玩内容仍暂停。

## 之前：接回原书册

用户纠正人物档案已经有设计，不需要重新制作。设置页“音乐库”下方的“人物档案”现直接进入原 `section[data-view="explorer-dossier"]`，复用 `UI参考/东北迪斯科/index.html` 中已有的展开书册、左侧李正照片、右侧属性纸张和四个侧签。正式页面原本就有这套结构和 CSS，本次保留原设计，没有重新绘图。

素材沿用 `public/assets/exploration-dossier.png`、`public/assets/dongbei-portrait-li-zheng.png`。原参考文件不改。刚新增的三人物介绍面板已经移除，配套脚本、样式和额外头像副本保存在 `.local/personnel-unused-ui`，不再参与发布。

入口与返回逻辑在 `index.html` / `scene.js`。从设置打开档案，返回按钮与 Esc 回到设置；从探索打开仍回到探索。嵌套返回保留设置的原主菜单／车站目标，保留音量与胶片草稿。原车站页面切换的自动存档会更新时间戳，但剧情节点、选择和进度保持不变。

原书册显示的等级、属性、升级按钮仍是原 UI 的演示内容。本次只接回页面，没有将这些数值变成真实养成系统，也没有新编人物资料。

验证：`npm run check` 通过；现有 HTML 流程测试加入主菜单和车站两条“设置 → 档案 → 设置 → 原场景”的回归检查。`scripts/qa-personnel-cdp.py` 使用固定工作 Google Chrome + 直接 CDP，在专用后台页面以隔离内存存储和静音进行 16 项检查，覆盖原页面、四个标签、键盘切换、返回来源、草稿及音乐库；1440×810 与 844×475 的书册截图已目视检查。记录在 `personnel-verification.json`。

旧 `personnel-dong-*`、`personnel-wang-*`、`personnel-compact-*` 截图仅是上一轮已被替换的版本；当前截图为 `personnel-original-book-1440.png` 与 `personnel-original-compact-844.png`。
