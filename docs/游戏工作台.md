## 4:3 预览切换（2026-10-04）

工作台游戏预览栏现在有“网页 / 4:3 / iPhone”三个按钮。点击 **4:3** 后，内嵌游戏视口按预览区可用宽高等比例缩放并居中，右下角显示实际视口尺寸；点击“网页”即可恢复填满预览区。切换不会重载游戏，选择随当前项目标签保存，重新打开工作台后恢复。游戏自身在 4:3 视口下使用 4:3 舞台。

按钮由共享工作台程序 `E:\blender\tool\html-dual-ai-workbench` 提供；已经打开的工作台窗口需要重新打开才能加载新界面。重开会结束该窗口中的终端会话，操作前应先保存终端工作。

桌面双击 **东北迪斯科工作台**，或运行根目录 `启动工作台.cmd`。

复用桌面“数学的防御协议工作台”的同一套 Electron 程序，固定连接 `E:\东北迪斯科` 和正式游戏入口。上方游戏预览，下方四个终端，默认 Codex，可分别切换到 DS Claude 或 PowerShell。保留实时更新、截图、指认 UI、复制粘贴、拖动分隔条和专注模式。指认区提供 1～4 四个目标，分别对应下方同编号终端；名称随 Codex、DS Claude 或 PowerShell 类型更新。指认信息填入后由用户按 Enter 提交。

游戏仍为已有的桌面、书法菜单、档案袋与 A000 车站。本次接入不修改游戏剧情或 UI 参考目录。

## 启动与配置

- 游戏服务固定为 `http://127.0.0.1:5173/`；已有本游戏服务时复用，没有时工作台运行 `npm run dev`。若端口被其他页面占用，报错且不终止进程。
- 关闭工作台只清理它启动的服务与终端；启动之前已经运行的游戏服务保留。
- 独立配置：`%APPDATA%\小游戏AI工作台\东北迪斯科`，与数学的防御协议的配置和预览存档分开。
- 工作台的内嵌预览与 Chrome 也分别保存进度。Chrome 原有存档仍在 Chrome 内，未迁移或清空。
- 共用程序：`E:\blender\tool\html-dual-ai-workbench`。启动脚本复用现有 Electron、终端和窗口功能，不复制 node_modules，不改数学的防御协议入口。
- 桌面快捷方式和窗口启动图标使用董点事选人卡裁切图 `public/assets/character-select/game-icon-dong-crop-v1.ico`；窗口标题与任务栏应用标识独立。2026-09-16 已更新桌面入口，已打开窗口在下次重开时加载新图标。2026-09-17 重建快捷方式并执行 `ie4uinit.exe -show` 刷新图标缓存，消除桌面残留旧图标显示。

需要重建桌面入口时，在项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\启动东北迪斯科工作台.ps1 -CreateShortcut -CheckOnly
```

网页自动化统一通过固定工作 Chrome 和直接 CDP `http://127.0.0.1:9223`；不使用网页控制插件，也不重启用户浏览器。Electron 的内嵌预览供用户操作，作为桌面工作台的一部分。
