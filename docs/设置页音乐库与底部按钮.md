# 设置页音乐库与底部按钮 · 2026-09-13

用户要求在设置页左侧增加“音乐库”纸条，并将“恢复默认”“应用设置”放到画面最下方，去掉背景。

## 画面

- 沿用档案袋、旧纸张和楷体文字。纸张、深灰墨色 `#393a34`、辅助灰绿 `#6c6f62`、按下时的旧红色 `#753b32` 与原页一致。
- 新纸条复用 `public/assets/entry-title-slip-v2.png` 的完整独立素材，文字由 HTML 叠加。底图继续使用 v4 与 v3 的透明轮廓蒙版；没有恢复旧“总入口”。
- 两个底部按钮从设置表单中移出，定位到画面下缘，居中排列。只保留文字与鼠标悬停下划线、键盘焦点；无图片背景、底色、边框及投影。

## 音乐库

- 当前收录用户指定的《东北迪斯科主页曲》与车站配乐 Dark Place，显示名称、用途、时长与试听操作。
- 在同一设置页内切换内容，不清空设置草稿。返回设置、Esc 或退出设置均结束试听，恢复场景配乐；音量沿用已应用的音乐音量，0保持静音。
- 使用既有 Web Audio 播放器和解码缓存，未创建第二套音频播放路径，也未修改两首配乐的正式场景绑定。
- 入口与布局：`index.html` / `app.css`；音乐库交互：`src/core/music-library.js`；试听与场景恢复：`src/core/music.js`。
