# A000 夜间开场 · 2026-09-13

第一眼呈现黑夜中的局部环境：主角在左下，老奶奶坐在右上候车亭的长椅上，面向主角来路；路灯照着她的脸、长椅与站前一小片路面。她头顶的感叹号引导首次点击。

视觉沿用现有二维手绘场景、楷体 UI 和胶片滤镜。夜色使用 `#010306`，暗处冷色 `#13222a`，灯下暖色 `#deb775`，感叹号 `#fff0b6`，旧木灰绿 `#797663`。画面焦点只放在灯下的人；开场目标框隐藏，远处物件名不提前暴露。保留原有菜单、工具栏与纸质对话界面。

`public/media/station-night.png` 是编辑原白天底图得到的新素材，原图保留。灯与坐姿老奶奶绘在底图内，感叹号与人物点击区域独立。精确提示词及来源在 `station-night-art.json`。没有人物转头或逐帧行走动画，人物朝向由静态画面表达。另有 MJ 候选保存在美术概念目录，不属于此实现的运行素材。

SVG 遮罩包含两个柔边可见区：车站灯区固定，玩家附近视野跟随二维坐标。遮罩在角色上方、交互目标下方，且不接收鼠标。感叹号静止显示；灯光与整幅画面不抖动。此前认可的胶片灰尘、划痕与纹理动态保持原实现。

新游戏仍从 `arrival` 保存，但不立即弹对话。点击感叹号或老奶奶后，主角走到她斜前方，到站独白才展开，随后直接进入相认与原三问。收起到站独白仍可点击她继续；进入相认后感叹号消失。旧版 `explore` 存档保持可用。站牌、长椅和岔路可以走近观察，预言与黑影结束后沿路进镇。存档票据使用同一夜景插图，仍不是保存时的动态截图。
