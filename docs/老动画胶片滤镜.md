# 老动画胶片滤镜

2026-09-13，用户最终明确要求：“你的滤镜是抖的，然后有一些老动画的划痕和灰尘那种”。因此动态仅发生在胶片纹理覆盖层；场景、人物、菜单和文字保持稳定。

## 当前效果

- 设置页修复：移除设置的即时切换例外，进入和离开复用原430ms纸张翻页。设置浅纸面上的四周黑色暗角增强，中央保持明亮；沿用原暗角层，滤镜关闭或强度0仍完全隐藏。百叶窗、橙色光影和雪花蒙版保留，唱片库的暗角不变。
- 用户随后仍认为四周清晰、怀疑图层遮挡。设置暗角现提升至舞台内 z-index 90，高于纸面、调色和雪花；使用独立空间蒙版、深黑覆盖及2–6px边缘模糊。默认65强度时中心透明、四角接近黑，四角实测亮度约为关闭暗角时的24%–27%，中央读数相同。Chrome四角命中测试确认该层实际在最上方，并恢复pointer-events:none保证按钮可点。
- 最新：用户认可密集雪花，要求中心更淡、四角更明显。颗粒与损伤层增加共用椭圆透明度蒙版，中心约18%，平滑增强到四角100%；这个比例乘在原有滤镜强度上。蒙版仅改变雪花可见度，48个尘点及原闪动节奏保留，调色和页面光影未改。
- 暖白、轻微褪色和柔和暗角作为固定调色层。
- 2026-09-14 用户认可雪花闪现并要求更多。细颗粒更新间隔由增强模式105–150ms改为65–95ms，平衡模式170–220ms改为110–155ms。
- 用户随后反馈5个尘点仍看不出区别。当前改为48个尘点，空闲时每帧72%概率闪现，停留1–2帧；默认65强度下增强模式实测同时平均约37个尘点，旧版约3个。15%的尘点尺寸为.28–.42cqw，其余为.1–.24cqw，深浅对比提高。
- 短纤维增至3个；2个细划痕节点分段、带透明断口，每隔约3–6秒出现一次。全局颗粒层系数从.32提高到.46，并加1.5对比度；损伤层系数从.86提高到1.1。设置页既有更强的纸面颗粒样式保留。
- 只有胶片损伤覆盖层作轻微错位；已完全移除画面的平移、补边缩放和原先的固定循环抖动。

## 设置

进入设置的“老动画胶片”，默认开启，强度 65。开关、强度和动态均即时预览；点击“应用设置”保存，直接返回取消本次未保存的滤镜调整。

强度 0 或关闭开关完全绕过滤镜。“动态关”保留静态调色、暗角和颗粒，同时移除动态尘点与划痕。平衡模式降低纹理更新频率；性能模式省略颗粒和损伤。隐藏页面或系统启用“减少动态效果”时停止动态定时器。

## 实现与保留

`src/core/retro-film.js` 管理固定的53个装饰节点和唯一的纹理更新定时器，不按帧创建或删除 DOM。`src/core/retro-film.css` 只对 `.grain` 和 `.projector-edge-snow` 更新纹理位置。调色仍由独立 backdrop-filter 覆盖层提供，不对整个舞台设置 filter。

`scene.js` 继续使用 `northeast-disco.settings.v1`，旧设置补齐新增字段。原始 PNG、故事、音乐、玩家存档及 UI参考均未改。设置使用原纸张底图和控件；没有新增运行依赖。

此前“整张画面每秒 12 次位移”和后续“偶发整幅画面轻晃”均已撤下，不能作为当前效果方向。调整前代码及旧验证记录保留在 `.local/film-overlay-before-20260913-155943`。

## 核验

最上层暗角修正：构建及 `.local/qa-settings-top-vignette.py` 的5项 Chrome 直接 CDP 检查通过，1440×810与844×475截图已目视核对，叠层、实际像素与设置返回记录见 `settings-top-vignette-verification.json`。工作台固定配置指向根 index.html 与5173服务，但本轮 computer-use 初始化报“failed to write kernel assets / os error 3”，未直接读取用户那个 Electron 窗口，不能把Chrome检查写为已确认其预览已刷新。
