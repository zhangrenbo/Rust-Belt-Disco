贴纸相框是已迁移正式图层 `T_对话角色照片 拷贝 12.png` 的逐字节副本；董点事、老太太和黑影使用原有对应人物照。原 `UI参考/东北迪斯科` 未改，未生成或裁切新素材。修改前文件保存在 `docs/dialogue-ui-before-restore-20260909.zip`。

## 实现

根目录现在直接使用参考版的 HTML/CSS/JavaScript 结构。保留原主菜单、档案袋、选人和设置视觉；在同一个 HTML 内增加 station 状态、对话、随身笔记、暂停和首场景结尾。原 `UI参考/东北迪斯科` 文件未修改。新增继续旅程按钮仅在有有效自动存档时出现；原“存档”按钮接入真实槽位。

游戏层为 DOM 上的 PNG 背景与透明人物，无 Canvas/WebGL/Phaser 运行时依赖。坐标为 1600×900 的二维平面，导航采用 20 像素网格和 A*，由最终场景绘制可行走多边形并为边缘保留脚部半径。候车亭、树丛和固定老太太占用区域不可穿越。交互对象分别指定点击区域和可到达的站立位置；中途改目标先结束正在走的短网格边，避免穿墙或瞬移。

完整流程：到站 → 自由观察 → 老太太相认 → 三问 → 七天预言及两个质疑分支 → 不要左转 → 黑影片段与四种回答 → 沿右侧道路离开 → A000 完成页。站牌、长椅、左侧岔路是补充观察，不作为强制收集数量门槛。离场必须完成预言与黑影，不能提前跳过剧情。

剧情依据为 `content/story/ink/D0_序章.ink` 中 A000 段。原稿有两版开局属性描述，本实现采用后面明确写出的“三问累计”版本：六基础属性全 1；派生属性博学 1、见微 1、坚毅 2、道德 0；按照职业、价值观与恐惧逐项结算。拒绝错误阶段或重复提交，属性由已选答案重新计算，避免反复交谈刷数值。

黑影回答保留 freedom/equality/morality/self 四个稳定键。七天信息是人物预言，笔记明确说明其尚未核实；不会生成虚假的 `clue_` 犯罪事实。

## 存档与运行

版本 1 的 A000 存档保存角色、场景、剧情节点、三个答案、观察记录、位置、预言、黑影和完成标记。读取时验证节点和选择一致性，拒绝损坏或未来版本；手工改出的非道路位置回到最近可站立点。位置保存到最后走完的网格点，页面关闭发生在半步时最多回退一小步。

每次选项、交互和移动结束自动保存；六个独立手动槽提供保存与读取。继续旅程可以恢复对话中途或场景完成页。「开始游戏」在选定角色后直接从头开始，不弹出继续／重开选择，并替换自动档（包括损坏的自动档），保留手动档。读取损坏档时拒绝载入并保留原文。存储权限/容量失败显示提示，已完成的选择仍留在当前会话内。

暂停、离开场景或页面转入后台会停止人物移动循环；移动结束也停止循环。只在进入对应页面时装入其 data-src 图像。画质“性能/平衡”会减少旧胶片粒子等界面效果，不宣称真实设备帧率。角色 PNG 为 1024×1536 RGBA，alpha 范围 0–254，1,088,756 个全透明像素，四角 alpha=0。

## 美术及打包

既有公交站、指定老太太参考、董点事肖像来自本地旧素材清单。新增斜视公交站、透明董点事以及固定老太太场景使用内置 image_gen；精确提示词、来源和生成路径见 `station-art-manifest.json`。

老太太的三个单独抠图尝试都返回了带棋盘格的 RGB 图片，全部拒绝接入。最终改用生成工具把固定老太太绘入完整背景，保留独立点击区域及碰撞占用。没有把假的棋盘透明图显示给玩家。失败尝试和未使用素材存入归档。

入口未使用的素材副本和被中断的旧试玩代码已归档，映射在 `station-archive-moves.json`。public 从 123 文件 / 220,102,431 字节降为 55 文件 / 97,756,813 字节，减少约 122 MB。172 个迁移文件仍保持原 SHA-256。总静态资源大小不等于首屏传输或解码内存。

生产构建主 JavaScript 约 41.7 KB（gzip 约 15.5 KB），CSS 约 129 KB。构建中修正了原 CSS 相对图片地址在输出子目录下失效的问题。游戏没有外部 CDN 依赖。
