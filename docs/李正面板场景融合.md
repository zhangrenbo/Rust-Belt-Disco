# 李正面板的场景颜色与前景雾

用户再次指出选人页左下李正的整组面板像场景外的物件，颜色不一致，也没有被雾笼罩。修正范围为李正的三张底纸、照片、标题印字与小图层，以及它们所在的左下雾场。

## 具体原因

原 `001_T_氛围雾2.png` 位于 z-index 2，李正六个图层位于 9、13、17、18、19、20，因此即便地面有雾，纸张、照片和印字仍全部画在雾上。这组图层也没有中央／上方纸片已有的独立接触阴影，亮米黄色与左下较暗的灰绿色地面不协调。

## 画面处理

沿用当前场景材质，不重新设计卡片：地面灰绿 `#57584f`、灰米纸 `#aca89b`、雾灰褐 `#aaa085`、暗墨 `#4e4f46`、微暖受光 `#d5cbb3` 为校准方向。李正位于画面较暗的左下方，纸张与照片应保留内容，但降低鲜黄和局部对比。

三张底纸使用 saturate(.45)、brightness(.8)、contrast(.92)，叠加沿原 alpha 轮廓的近接触影和较淡柔影；照片使用 saturate(.52)、brightness(.83)、contrast(.9) 及相同方向的投影。印字同步使用纸张调色。所有原图不透明度保持 1，不通过让纸张半透明露出地面来假装融合。

复用原雾图，不新增雾素材。原后景雾与新增前景雾共用完全相同的世界坐标、尺寸和图源，以 60%～70% 世界高度的互补纵向蒙版过渡。前景雾位于 26 层，覆盖李正整组纸张、照片、文字及同一区域警徽；角色按钮仍在 35 层，雾不拦截输入。上方和中央主体保留原布置，雾仍随已有镜头移动和缩放，不新增动画计时器。
