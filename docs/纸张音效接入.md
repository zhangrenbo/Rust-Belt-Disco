# 纸张音效接入

用户于2026-09-14希望游戏加入符合美术的音效，尤其喜欢纸张摩擦声。第一组交付后，用户明确评价“完美”，本组声音及与界面的搭配已获认可，作为后续纸张音效的风格依据。此反馈独立于下方交付前的机器检查，不代表所有设备的实体扬声器均经过验证。

| 操作 | 声音 | 完整时长 |
| --- | --- | --- |
| 页面翻页、打开／返回唱片库、打开／返回人物档案 | 两段翻书素材交替 | 0.430／0.769秒 |
| 人物纸签切换、唱片目录切换、存档票据打开／关闭 | 短翻纸摩擦 | 0.231秒 |
| 设置印章选项、恢复默认、应用设置 | 书本落桌素材作较低音量的落章轻响 | 0.277秒 |
| 音效滑条完成调整 | 短纸声试听当前音量 | 0.231秒 |

素材来自[Kenney RPG Audio](https://kenney.nl/assets/rpg-audio)，作者Kenney Vleugels，CC0 1.0。原始ZIP保存在`.local/kenney-rpg-audio-original.zip`，运行时文件与原许可在`public/media/sfx`，来源、哈希和处理参数见`paper-sfx-source.json`。没有使用音效生成服务，也没有合成噪声层。保留每段完整声音，仅做120Hz高通、6800Hz低通、响度调整、软限幅及2ms／8ms首尾淡化。四个WAV合计约160KiB。

`src/core/ui-sounds.js`预载并缓存四段声音，通过成功交互的语义事件发声，鼠标和键盘共用。页面载入、悬停、重复选中和禁用角色签不发声；黑色UI展示场景没有翻纸转场音。85ms触发间隔与最多两路同时播放限制连续操作叠加；加载迟到不补播历史点击，页面隐藏时停止纸声并暂停其音频上下文。

音效使用独立Web Audio通道，响应既有“音效音量”，不随音乐音量改变。沿用音量即时自动保存；0立即停止当前音效，新音量在静止声道上也直接更新。恢复默认仍是预览，应用后保存。未增加悬停轮询或修改存档格式。音乐测试初始化脚本兼容两个音频上下文，并为两者各自使用分析器与静音输出，原`__recordQA`继续指向音乐。

验证：`npm run check`通过18项测试、172个迁移哈希、79个资源路径与生产构建。`qa-paper-sfx-cdp.py`通过固定工作Google Chrome + 直接目标CDP验证28项，包含实际音频波形、每次操作的音源数量、键盘纸签、音效与音乐独立静音、844宽实际滑条操作、27音量返回与真实刷新后保留。使用独立真实存储前缀并清理，玩家原始键未改。见`paper-sfx-verification.json`；四个音效的源码／HTTP／构建哈希一致，见`paper-sfx-assets-verification.json`。没有操纵或重启用户Electron工作台，未将机器检查标记为人类试听通过。

`paper-sfx-preview.wav`依次播放两段翻页、短纸声、落章轻响，采用默认音效音量84及游戏内各自增益，供用户试听。
