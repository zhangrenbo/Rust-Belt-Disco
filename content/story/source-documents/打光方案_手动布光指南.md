# 手动布光方案 — 去掉场景自动光源

## 目标效果
像电影剧组一样：黑暗的空舞台，只有你亲手放的灯才有光。
不依赖 Unity 的默认 Directional Light 和环境光——与《极乐迪斯科》的手绘打光感一致。

---

## Step 1：关掉所有自动光源

### 1.1 删 / 禁用 Directional Light
- Hierarchy 里找到 `Directional Light`（通常叫 "Directional Light" 或 "Sun"）
- 直接 **删除** 或 Inspector → 取消勾选（左上角的小勾）

### 1.2 把环境光变黑
```
Window → Rendering → Lighting
  ↳ Environment
      ↳ Lighting → Source：改为 "Color"
      ↳ Ambient Color：设为纯黑 (0, 0, 0)
      ↳ Intensity Multiplier：改为 0
```

### 1.3 把反射探针关掉
```
Window → Rendering → Lighting
  ↳ Environment
      ↳ Reflections → Source：改为 "Custom"
      ↳ Cubemap：留空（或指定一张全黑 Cubemap）
      ↳ Intensity Multiplier：0
```

### 1.4 关 Realtime GI
```
Window → Rendering → Lighting
  ↳ Realtime Lightmaps → 取消勾选
```

**效果验证：** 场景里一片漆黑，正确。

---

## Step 2：URP 管线的附加光源上限

你的 `PC_RPAsset` 里当前设置是 **4 个额外光源/每物体**。
如果场景里灯多，需要提高这个数字：

```
Assets/Settings/PC_RPAsset.asset（Inspector 打开）
  ↳ Lighting → Additional Lights
      ↳ Per Object Limit：改到 8 或 16
```

---

## Step 3：手动布光套路

### 布光逻辑（DE 风格）
- **没有日光**——一切光来自场景内的灯具、火光、窗口
- **冷暖对比**：主光偏暖黄（路灯色温约 2700K = R:1 G:0.75 B:0.4），
  补光偏冷蓝（天光溢散约 R:0.5 G:0.6 B:0.8）
- **光圈小、衰减快**：没有大面积泛光，光线边界清晰
- **阴影密**：暗部要够暗，冷色占主导

### 推荐灯具组合（一个场景节点）

```
SceneLights/
├── PL_路灯_001        Point Light  暖黄  Intensity: 3  Range: 12
├── PL_路灯_002        Point Light  暖黄  Intensity: 3  Range: 12
├── SL_窗光_北侧       Spot Light   冷白  Intensity: 2  Range: 8  Angle: 60°
├── PL_火堆            Point Light  红橙  Intensity: 5  Range: 6  (带闪烁 script)
└── DL_天光补光        Directional  冷蓝  Intensity: 0.3  (非常微弱，模拟天空散射)
```

> `DL_天光补光` 只有 0.3 强度，是给暗部一丝冷色，不是"太阳"。
> 如果觉得暗部已经够冷（材质 AmbientColor 有冷色），可以不要。

### 实用参数参考

| 灯型 | 色温 / 颜色 | Intensity | Range |
|------|------------|-----------|-------|
| 路灯（钠灯老式） | `#FFA855` (R:1 G:0.66 B:0.33) | 2.5–4 | 10–15 |
| 火堆 / 火炬 | `#FF6A20` + 闪烁 | 4–8 | 5–8 |
| 霓虹灯箱 | 色彩饱和，按颜色定 | 1–2 | 3–5 |
| 天空散射（冷补） | `#8AADCC` | 0.1–0.4 | ∞ |
| 窗户透光 | `#E8DFC0` 暖黄白 | 1–2 | 6–10 |

## Step 4：材质侧如何配合

`DiscoTerrain.shader` 和 `DiscoSnow.shader` 都有自己的 `_AmbientColor`：
- 这是**绕过 Unity SampleSH 的纯手动环境光**
- 把 Unity Lighting 窗口里的 Ambient 设成黑色之后，
  场景暗部的颜色完全由材质里的 `_AmbientColor` 控制
- **推荐值**：`(0.07, 0.08, 0.11, 1)` → 极暗的蓝灰，让暗部不是死黑

---

## Step 5：让场景里的旧材质（URP Lit）也配合

现有场景里有大量用 `URP/Lit` 的材质，它们也会响应手动放的灯。
为了配合 DE 风格，批量调整这些材质：
- Smoothness → 0（全哑光，无高光）
- Metallic → 0
- Emission → 0（自发光物体单独处理）

可以写一个 Editor 脚本批量设置，如需要告知。

## 常见问题

**Q：场景彻底黑了，连 DiscoTerrain 都看不到？**
A：材质的 `Ambient Strength` 最低设到 0.3 左右，保证暗部有基础显色。

**Q：点光源就是不打到地形上？**
A：检查 PC_RPAsset → `Additional Lights Per Object Limit`，
Terrain 对象通常算一个大物体，确保限制 ≥ 4。

**Q：附加光源打在地形上没有阴影？**
A：PC_RPAsset → `Additional Light Shadows` → 打开；
同时确认 Light 组件的 Shadow Type 不是 "No Shadows"。

**Q：想要 DE 那种"光圈内有质感，光圈外几乎全黑"的感觉怎么调？**
A：Point Light 的 `Intensity` 调高（5–8），`Range` 调小（6–10），
然后 Falloff 选 Physical（平方衰减），光会更快衰减到黑。
