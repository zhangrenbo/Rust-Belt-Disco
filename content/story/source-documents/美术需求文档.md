# 东北迪斯科 · 美术需求文档

> 本文档列出游戏中所有需要制作的场景、子区域、道具、光照/天气变体，以及场景间的连通关系。
> 基于 XMIND 剧情文件 + 场景地图.md 整理。

---

## 一、场景总表

共 **19个主场景**，**约35个子区域**，需要建模的独立可游玩空间约 **25-30个**。

## 二、逐场景美术需求

---

### S01 叔叔家

**定位**：董点事 A 线主场。D0-D7 反复回来的"家"。

**外观**：
- 镇上普通民房，两层，外墙贴了一半白瓷砖（钱不够只贴到一半）
- 铁栅栏门，门口台阶上堆着轮胎和机油桶
- 屋顶有铁皮搭的棚子（晾衣服用）

**子区域（5个）**：

| 子区域 | 美术要点 |
|--------|----------|
| **客厅** | 老式沙发（套着洗旧的沙发巾）、21寸CRT电视、茶几上烟灰缸和茶渍、墙上挂叔叔和父亲年轻时合影（关键道具）、年画、日历 |
| **厨房** | 煤气灶、铝锅、搪瓷盆、墙上油渍重、案板上永远有咸菜坛子。清晨：桌上两碗白粥一碟咸菜 |
| **二楼主卧/董点事房间** | 单人床、旧书桌、随身听（关键道具）、磁带若干、窗户可以看到街道 |
| **二楼小虎房间** | 门上有锁（小虎锁着不让进）、很小、书包和校服、墙上贴着动漫海报 |
| **阁楼** | 灰尘厚、纸箱子堆满、母亲的遗物（旧衣服、账本、照片）、光线暗只有一个小窗 |

**光照变体**：
- 清晨（06:00）：厨房亮灯，客厅暗
- 白天：自然光从窗户进来
- 傍晚（17:00+）：暖黄灯泡，影子拉长
- 夜晚（22:00+）：只有客厅一盏灯，叔叔在灯下喝酒抽烟

**关键道具**：
- 墙上合影（叔叔+父亲年轻时，关键互动物）
- 随身听+磁带（董点事噩梦系统触发物）
- 阁楼纸箱（母亲遗物，可翻找）
- 咸菜坛子、白粥（生活气息）

---

### S02 修车店（省道）

**定位**：叔叔的谋生场所。A 线日常场景。

**外观**：
- 省道边上，铁皮棚子搭的
- 棚子里堆着轮胎、千斤顶、扳手、废油桶
- 棚子外面几个塑料凳子，一张折叠桌——打麻将用
- 一辆半拆的面包车停在旁边（长期占位，可能永远修不好）
- 招牌：手写的"修车"两个字，红漆，半褪色

**光照**：
- 棚子内昏暗（铁皮遮光），靠一盏白炽灯泡
- 棚子外阳光直射（D1-D2），D3+雾天光线扩散

**关键道具**：
- 麻将桌+凳子（叔叔的朋友们在这打牌）
- 工具架（扳手、螺丝刀、气泵）
- 叔叔的旧收音机（放在工具架上，播新闻）

### S03 便利店（废弃凶宅）

**定位**：核心场景。母亲被杀的地方，十三年废弃。全线可达。

**外观**：
- 两层小楼，卷帘门（永久拉下，锈死）
- 外墙熏黑的痕迹（火烧过的）
- 二楼窗户从里面用报纸遮住
- 门口台阶上长了草
- 旁边紧挨着一条胡同（→S14）
- 对面就是职高（→S10）

**子区域（3个）**：

| 子区域 | 美术要点 |
|--------|----------|
| **一楼店面** | 废弃货架（倒了几个）、柜台还在（灰尘覆盖）、地面有白色尸体轮廓标记（已褪色）、墙根沿线有**浇灌汽油的烧焦痕迹**（不是泼溅——是沿墙根一圈）、阳光从破窗照进来时灰尘悬浮在光柱中、蛛网 |
| **二楼住所** | 楼梯窄且嘎吱响、卧室（床架还在，被褥早没了）、窗户被从里面用报纸遮住（关键细节——有人来过？）、墙上有奖状和全家福照片（褪色） |
| **门口/外部** | 卷帘门、门口台阶（草从缝里长出来）、隔壁是老太太家的门、门口可以停车（宏大的黑色轿车会停在这里） |

**光照变体**：
- 白天：外面亮，里面暗。阳光从破窗打进光柱。
- 夜晚：完全黑暗，只有手电筒的光。恐怖感。
- D3+雾天：外面雾渗进来，一楼能见度极低。

**关键道具**：
- 白色尸体轮廓（地面）
- 墙根烧焦痕迹
- 二楼照片+奖状
- 卷帘门（叙事物件——父亲往下面塞钱）
- 宏大地产名片（门口被留下）

**特殊需求**：
- 需要"十三年前回忆版"——完好的便利店（噩梦系统/闪回用）
- 回忆版：货架整齐、灯亮着、柜台后面站着母亲的模糊身影

### S04 王少鹏的诊所（中医抗癌馆）

**定位**：C 线主场。假中医的伪装。

**外观**：
- 镇上十字路口一间门面房
- 铁门半掩
- 门上手写牌子："王氏中药馆 · 内科外科跌打损伤"
- 门口贴着手写广告（"祖传秘方""三代传人"——全是假的）

**子区域（3个）**：

| 子区域 | 美术要点 |
|--------|----------|
| **前厅/诊疗室** | 柜台、药柜（格子里摆着没有标签的药瓶——西药换了中药壳）、一张诊疗床、墙上挂着"妙手回春"锦旗（自己做的）、气味：中药味混着消毒水味 |
| **后屋（奶奶房间）** | 帘子隔开的、一张床、呼吸机（核心音效：嘶嘶声+滴滴声）、奶奶躺着（植物人）、床头有老照片、窗帘永远拉着 |
| **门口/街面** | 铁门、手写广告、街对面可以看到其他店铺 |

**光照**：
- 前厅：日光灯，偏冷白色（假装专业）
- 后屋：暗，只有呼吸机的指示灯闪烁，帘子透过来的一点光

**关键道具**：
- 没有标签的药瓶（可互动查看）
- 呼吸机
- 锦旗（假的）
- 帘子（隔开前厅和后屋）

### S05 镇公安局

**定位**：B 线主场。权力中心。

**外观**：
- 三层旧楼，水泥外墙
- 门口挂着"XX镇公安局"的牌子
- 停车场在楼下（几辆旧警车）
- 走廊贴着"禁止吸烟"标语（但到处是烟味）

**子区域（6个）**：

| 子区域 | 美术要点 |
|--------|----------|
| **大厅/前台** | 值班台、公告栏（通缉令、防火通知）、塑料椅子、地面磨得发亮的水磨石 |
| **李正办公室** | 普通办公桌、文件堆、烟灰缸满的、窗户对着街道、墙上有地图（标注火灾位置——可随剧情增加标记） |
| **陈国涛办公室** | 更大更整洁、墙上挂总书记头像（画像后面藏着保险箱——关键道具）、实木桌、抽屉（底部贴着半撕的便签）、柜子上锁 |
| **会议室** | 长桌、折叠椅、投影幕布（坏的）、白板上有案件时间线（D2通报会后会有内容） |
| **档案室** | 灰尘厚、铁柜排列、底层抽屉（十三年前案卷——泛黄纸张）、光线暗、只有一盏老旧日光灯嗡嗡响 |
| **楼下停车场** | 水泥柱、旧警车、角落（李正和董点事密谈的地方）、光线暗 |

**关键道具**：
- 保险箱（陈国涛办公室画像后面，D1-D5长线谜题）
- 十三年前案卷（档案室，泛黄）
- 指纹比对报告（审批日期比报告早三天——关键线索）
- 份子钱本（如果李正去了婚礼，回来后可翻看）

### S06 李正家

**定位**：B 线私人空间。出轨暗线发生地。

**外观**：
- 公安局家属楼里的普通单元房
- 两室一厅

**子区域**：

| 子区域 | 美术要点 |
|--------|----------|
| **客厅** | 沙发、电视、茶几、冰箱（嗡嗡响）、窗户外面雾（D2+） |
| **卧室** | 双人床、床头柜、闹钟、衣柜（老婆的衣服）。**Track B线索**：水池边两个杯子、空气里红塔山烟味（王涛抽的牌子） |
| **厨房** | 老婆在做饭（D1早上场景）、冰箱上贴着便签 |

**特殊需求**：
- 需要"Track A/Track B"两种状态：
  - Track A（未发现出轨）：正常家庭状态
  - Track B（撞见线索）：水池的杯子、烟味、枕头上的头发等细节

### S07 镇上街道（枢纽）

**定位**：所有场景的连接枢纽。玩家在场景间移动时经过。

**构成**：
- **主街**：两边是关了门的店铺（铁卷帘门拉下来，上面贴着"旺铺转让"）、电线杆上挂着褪色的横幅、柏油路面有裂缝
- **十字路口**：王少鹏诊所在这里、路口有一个不亮的红绿灯
- **供销社门口**：还在营业，门口有鲜花和鞭炮卖
- **小巷**：居民区的巷子，晾衣绳、搪瓷盆、老人坐在门口

**光照/天气变体（极其重要）**：

| 时间 | 天气状态 | 美术描述 |
|------|----------|----------|
| D1 白天 | 无雾，灰蒙蒙 | 东北夏末的天。不算晴也不算阴。远处钢铁厂烟囱冒白烟。 |
| D1 夜晚 | 无雾 | 路灯亮了（黄色光），大部分店铺黑着 |
| D2 早上 | 薄雾 | 灰白色的雾贴着地面，像棉花塞住了街。远处模糊。 |
| D2 傍晚 | 雾加重 | 路灯提前亮了。光被雾切成一团一团的黄。 |
| D3 白天 | 浓雾 | 影响能见度。对面的人看不太清脸。婚礼的红色在雾里像水彩化开。 |
| D3 夜晚 | 浓雾 | 三米外看不清人。路灯变成模糊的光晕。恐惧感。 |
| D4-D5 | 越来越浓 | D5能见度低于50米。路灯变成雾里的光点。 |
| D6 | 雾+寂静 | 无火无信。街上几乎没人。死寂。 |
| D7 早上 | 雾开始散 | 第一次看到天空。河水上涨可见。 |

**关键道具/环境物件**：
- 关了门的店铺（铁卷帘门+转让告示）
- 电线杆上褪色横幅（"安全生产""计划生育"之类）
- 不亮的红绿灯
- 路灯（D2+雾天的光晕效果是重要视觉标记）
- 远处钢铁厂烟囱（D1可见，D2+被雾吞没）

### S08 面馆（镇中心）

**定位**：日常场景。A/B 线首次见面点。

**美术要点**：
- 小店面，四五张桌子，塑料凳
- 门口贴着褪色的菜单（手写、过了塑）
- 靠窗角落有一个塑料加高凳（给小孩坐的——母亲以前带董点事来吃面）
- 老板娘在灶后面，蒸汽腾腾
- 墙上挂着"本店不赊账"

---

### S09 东山坟地

**定位**：D1（看父亲坟）、D7（集体葬礼可能经过）。

**美术要点**：
- 山坡上，杂草丛生
- 父亲的坟：新土（刚葬不久，D0 葬礼），旁边有一瓶没开封的白酒落了灰（谁放的？）
- 远处有一片旧坟（文革时期的）——墓碑密集，字迹模糊
- 天气：D1 灰蒙蒙，风大

---

### S10 职高（职业高中）

**定位**：表弟小虎上学的地方。D5门卫是双胞胎关键翻转点。

**外观**：
- 铁大门，门口有保安亭（门卫在里面打盹/看报纸）
- 围墙上有爬山虎
- 校内：操场（跑道线褪了色）、教学楼（走廊晾衣绳上挂着校服）

**子区域**：

| 子区域 | 美术要点 |
|--------|----------|
| **校门口** | 铁门、保安亭、门卫（关键NPC——D5翻转）、公告栏 |
| **校内** | 操场、教学楼走廊、晾衣绳上的校服 |
| **天台** | 通往天台的铁门（挂锁）、天台上可以俯瞰半个镇子、D2 C010_PRE 朱启渲事件发生地 |

### S11 县医院

**定位**：不在镇内（在县城），需要坐车去。D2+。

**美术要点**：
- 县级医院，比镇上的建筑新一些但也旧
- 走廊：消毒水味、淡淡的焦味（烧伤科）、日光灯嗡嗡响、有个年轻民警在走廊椅子上打瞌睡（守卫）

**子区域**：

| 子区域 | 美术要点 |
|--------|----------|
| **走廊** | 长走廊、绿色墙裙、日光灯、椅子上睡着的守卫 |
| **烧伤科病房** | 单人床、监护仪（绿线+嘟嘟声）、呼吸机（嘶嘶声）、朱启渲躺在床上（全身纱布）、窗帘半拉 |

---

### S12 镇西民房废墟（火灾现场）

**定位**：D2+新出现的场景。每次纵火都可能有新的火灾现场。

**美术要点**：
- 焦黑的断壁残垣
- 警戒线（黄色）
- 围观的人群（远处站着，交头接耳）
- 年轻民警站岗
- 灰烬气味（D3+雾天让灰烬味更浓）
- 地面有水渍（消防灭火后）

**特殊需求**：
- 可能需要多个火灾现场变体（D1-D5每次纵火目标不同）
- 或者一个通用火灾现场模板+不同的废墟道具组合

---

### S13 婚礼场地

**定位**：D3限定场景。王少鹏的婚礼。

**外观**：
- 镇上唯一还开着的饭店，或者露天流水席搭的棚子
- 红色：红桌布、红塑料凳、红双喜字、大红灯笼
- 棚子外面：鞭炮碎屑满地、大喇叭（放二人转和流行歌）
- 雾中的红——最重要的视觉效果：喜庆的红色和不祥的白雾混在一起

**子区域（4个）**：

| 子区域 | 美术要点 |
|--------|----------|
| **门口** | 收份子的桌子（一个本子、一支笔、一个铁盒装钱）、鞭炮碎屑、红地毯（廉价的那种，已经踩脏了） |
| **正厅/席面** | 圆桌（8-10桌）、红桌布、一次性筷子和纸杯、啤酒瓶堆在桌角、大喇叭音响、新郎席（亲属位空着——核心视觉线索）、新娘席（岳父家那边坐满了人） |
| **偏房** | 杂物间改的。旧沙发、几箱啤酒、多余的折叠椅堆在角落、灯泡瓦数低偏暗、一扇小窗（雾渗进来） |
| **后屋（奶奶）** | 和诊所后屋类似布置，呼吸机、奶奶躺着、外面鞭炮声和里面呼吸机声形成对比 |

**特殊视觉效果**：
- 雾+红色=最核心的画面。红灯笼在雾里变成模糊的红色光晕。
- 刘小红走向王少鹏那一幕：全场安静，她一个人穿过人群，所有人看着她——需要特殊镜头/光照处理

**关键道具**：
- 份子本（可翻看——王家来客数=0）
- 空着的亲属席位（父亲位/母亲位/爷爷位=空椅子）
- 师傅的酒杯（他喝得摇摇晃晃）
- 刘小红的啤酒瓶（偏房地上）

### S14 便利店旁胡同

**定位**：D3夜限定。强奸事件发生地。

**美术要点**：
- 便利店侧面延伸出去的窄胡同
- 白天：居民抄近道的小路，两边是废弃仓库的墙壁
- 夜晚：没有路灯，完全靠月光（如果有的话）和手电
- D3夜+浓雾：三米外看不清人，声音从深处传来
- 地面：碎砖、铁管（可互动拾取的武器）、垃圾

---

### S15 退休警员家

**定位**：B 线 D2 走访。

**美术要点**：
- 普通居民家，和叔叔家类似但更老旧
- 客厅里有个藤椅，老人坐在上面
- 墙上有旧照片（穿警服的年轻时候）
- 茶几上有药瓶和保温杯

---

### S16 镇东头空地/河边

**定位**：D7限定。集体葬礼。

**美术要点**：
- 河边空地，杂草
- 河水已明显上涨（D7能看到水位线比之前高了很多）
- 棺材排列在空地上（2-8口，数量随玩家选择变化）
- 远处可以看到搬迁的迹象（卡车、打包的家具）
- 天气：D7早上雾开始散——第一次看到蓝天
- 呼应D0（一个人的葬礼→集体葬礼）

**关键视觉**：
- 棺材数量可变（最少2口、最多8口）——需要动态布置
- 河水（叙事压力的视觉化——时间在流逝，水在上涨）

## 三、全局美术系统

### 3.1 雾系统（D2-D7 核心视觉）

| 天数 | 浓度 | 视觉描述 |
|------|------|----------|
| D1 | 无 | 正常东北天，灰蒙蒙 |
| D2 早 | 薄雾 | 贴着地面，远处模糊 |
| D2 晚 | 中雾 | 路灯光被切成一团团黄色 |
| D3 | 浓雾 | 对面看不清脸。红色婚礼在雾里化开。 |
| D4 | 更浓 | 街上行人稀少 |
| D5 | 最浓 | 能见度50米以下。路灯=雾里的光点。群架在雾中发生。 |
| D6 | 浓+寂静 | 无火无信无人。死寂。 |
| D7 早 | 散开 | 第一次看到天空和远处的山。河水上涨清晰可见。 |

### 3.2 光照系统

每个场景至少需要以下光照状态：
- **白天**（08:00-17:00）
- **傍晚**（17:00-19:00）：暖黄色调，影子拉长
- **夜晚**（19:00-06:00）：路灯黄光+室内灯泡暖光
- **清晨**（06:00-08:00）：冷灰色调

室内场景光源：
- 白炽灯泡（暖黄，叔叔家/面馆/修车店）
- 日光灯管（冷白，公安局/医院/诊所前厅）
- 呼吸机指示灯（绿色闪烁，诊所后屋/医院病房）
- 无光源（便利店内部/胡同/档案室——需要手电效果）

### 3.3 时代美术风格参考

**年代**：2000年代初的东北小镇（下岗潮后）

**关键视觉元素**：
- 搪瓷缸子、搪瓷盆（蓝边白底，印着"为人民服务"）
- CRT电视（21寸，带天线）
- 红白蓝编织袋（搬家/装东西用）
- 铁皮暖壶（印花的）
- 煤球/蜂窝煤（屋外可能堆着）
- 对联（门框上贴着，褪色了）
- 蛤蜊油、大宝SOD蜜（梳妆台上）
- 红塔山/哈德门烟盒（烟灰缸里）
- 牛栏山/老村长酒瓶
- 军大衣、棉鞋、毛线帽
- 自行车（二八大杠）停在门口
