# 小镇地形设计（叙事功能型）

> 本文档定义小镇的立体地形——高差、地貌、关键地形特征。所有地形服务于叙事和游戏机制。
> 与场景设计总表（XMIND 三十六章）配合使用，本文档提供"第三维度"。

---

## 一、总纲：河湾盆地模型

镇子坐落在**河流弯道内侧的一个天然浅盆地**中。

- **三面环水**：东、南、东南被河弯包裹
- **西北高地**：缓坡丘陵+矸石山
- **冲积平地**：河弯内侧沉积形成的平坦建设用地

**这个地形决定了一切：**

| 问题 | 地形解释 |
|------|----------|
| 为什么镇子建在这里 | 河弯内侧冲积平地，适合建设 |
| 为什么北高南低 | 地势从西北丘陵向东南河谷倾斜 |
| 为什么南端先淹 | 盆地最低点在南端河弯底部 |
| 为什么雾浓 | 盆地地形困住冷湿空气，雾气下沉聚集 |
| 为什么水库会淹没全镇 | 镇子在河谷盆地里，水位一涨无处可退 |

## 二、等高分区（5级）

```
海拔示意（相对高度，河面D1正常水位 = 0m）

+45m ▲ 矸石山顶（人造·煤矿废石堆）
+30m ▲ 西北丘陵 / 钢铁厂台地
+20m ── 镇北行政区（派出所 / 镇政府）
+15m ── 镇中商业区（老槐树 / 十字路口）
+10m ── 镇南居民区 / 便利店
+ 5m ── 河滩 / 堤坝顶部
+ 0m ▼ 河面（D1正常水位）
```

### 第一级（+30m～+45m）：矸石山 + 厂区台地

#### 矸石山（煤矿废石堆）

- **位置**：镇子西北方，约800米外
- **高度**：相对河面+45米，方圆几公里内最高点
- **形态**：灰黑色锥形人造山丘，底部直径约200米，无植被。表面碎石松散，雨天湿滑
- **特殊现象**：煤矸石内部氧化发热，偶尔从缝隙冒出白烟（自燃）

**叙事功能：**
- **全景观察点**：站在山顶可以看到整个镇子——从北面的烟囱到南面的便利店废墟
- **火光定位器**：D1-D5夜间纵火时，从矸石山能准确判断着火位置和方向
- **自燃意象**：矸石自燃冒白烟 vs 纵火冒黑烟——"这座山也在烧"——视觉平行
- **WYP隐喻**：虚无主义者站在废物堆成的山顶俯瞰一切

**游戏机制：**
- D4-D6可以选择去矸石山，消耗半天时间
- 收获：白天看到搬家卡车规模，夜间精确定位火光方位
- 雾天：矸石山在雾线以上（+45m），唯一能俯瞰全镇的位置

#### 钢铁厂台地

- **位置**：矸石山以东，镇子正北方约500米
- **高度**：+30米，建在一处自然台地上
- **形态**：围墙+大门紧锁，烟囱可见（已停产但偶有余热白烟）
- **不可进入**：只作远景出现

**叙事功能：**
- **天际线地标**：无论站在镇子哪里，抬头北望都能看见烟囱——它是这个镇子的"原点"
- **职高天台视线**：南面便利店 / 中间老槐树 / 北面烟囱——三点一线=镇子的脊柱
- **D7浓雾散去**：烟囱重新可见="我们还在这里"

---

### 第二级（+15m～+25m）：镇北台地·行政区

- **位置**：主街北段
- **地势**：缓坡台地，比镇中高约5-8米
- **建筑**：派出所、镇政府、宏大地产办公室、中医馆
- **地面**：水泥路面较好，有路灯（部分亮着）

**叙事功能：**
- **权力在高处**：行政机构占据地理高点→D7最后被淹→象征权力"安全感"的虚假性
- **视野优势**：李正从派出所二楼窗户看出去，能看到主街大部分→刑侦视角的物理基础
- **雾天差异**：台地上雾比低处薄→警察"看得比居民远"→但看不到南端的便利店→信息盲区
- **D6-D7"安全岛"**：镇南已积水时，镇北还干着→人群聚集→社会压缩→矛盾激化

---

### 第三级（+10m～+15m）：镇中坡地·商业区

- **位置**：主街中段（老槐树、十字路口、面馆、修车铺）
- **地势**：从镇北台地向南的过渡斜坡。**老槐树恰好在坡度转折点上**（+15m）
- **建筑**：面馆、修车铺、新华书店、已关门的店铺
- **地面**：水泥路面坑洼，两侧明沟排水

**叙事功能：**
- **老槐树=分水岭**：物理意义——雨水从这里开始向南流。叙事意义——镇中是"现在"，镇北是"权力"，镇南是"过去"
- **排水沟**：主街两侧水泥明沟，正常时干着/有垃圾。D4起水流汹涌→D6溢出沟面
- **十字路口**：主街与一条东西向小路交叉。东通河边，西通农田/丘陵——镇子唯一的十字路口
- **声音传播**：坡地上声音向下传播比向上容易→修车铺的打铁声能传到南端，反过来不行

---

### 第四级（+5m～+10m）：镇南低地·便利店区

- **位置**：主街南段（便利店废墟、胡同、居民楼、职高）
- **地势**：盆地最低区域之一。地面常年潮湿，D4起开始积水
- **建筑**：便利店废墟（最重要场景）、胡同、旧居民楼（父亲曾住对面）、职高
- **地面**：水泥路面破碎，有些地方回归泥地

**叙事功能：**
- **便利店在最低点**：物理上→第一个被淹→物证被水威胁。叙事上→母亲的记忆在最底层→你必须"往下走"才能接近真相
- **积雾最浓区**：冷空气下沉到盆地底部→南端雾比北端浓两倍→D3夜胡同事件"什么都看不见"有地形依据
- **胡同=峡谷效应**：窄巷两侧高墙→空气流通差→雾在胡同里更浓→声音被两面墙反射→方向感混乱
- **D7洪水线**：水位到膝盖时，便利店内已不可进入→"你没有时间了"→地形制造紧迫感

---

### 第五级（0m～+5m）：河滩·堤坝

- **位置**：镇子东侧和东南侧
- **地势**：河岸缓坡→水泥堤坝→石阶8级→河面
- **设施**：堤坝（有水位标尺·红色刻度）、岸边柳树、土路通回镇上

**叙事功能：**
- **水位标尺=倒计时器**：每天石阶少一级→视觉化的时间压力
  - D1-D3：石阶露4-5级（正常）
  - D4：露4级
  - D5：露3级
  - D6：露2级
  - D7：全淹（水漫堤坝）
- **河对岸=外面的世界**：晴天能看到对岸农田/远山，雾天什么都看不见→"外面的世界在消失"
- **D7水漫堤坝**：堤坝是镇子和河流之间最后的屏障。水过堤=一切不可逆

## 三、关键地形特征详述（7处）

### 1. 矸石山（+45m · 全景制高点）

| 功能 | 说明 |
|------|------|
| 火光定位 | D1-D5夜间，站在山顶→能看到整个镇子的火光方向和距离 |
| 全景观察 | 唯一能同时看到便利店+老槐树+烟囱的地面位置（职高天台也可但视角更低更近） |
| 角色独白 | 高处的沉默——站在废物堆成的山上看一个正在死去的镇子 |
| 自燃烟雾 | 煤矸石自燃冒出的白烟 vs 纵火的黑烟——视觉对比 |
| 可选去处 | D4-D6可以去矸石山→消耗半天但获得信息（搬家卡车规模/夜间火光方位） |

**物理细节：**
- 上山路：一条碎石小道，约15分钟步行
- 山顶平台：自然踩出的5×5米平地，有人来过的痕迹（烟头、啤酒瓶）
- 雨天：碎石湿滑，上山有风险（坚毅检定）
- 夜间：无照明，需手电筒

---

### 2. 废弃铁路路基（+12m · 南北隐蔽通道）

- **位置**：主街以西约100米，与主街平行，南北走向
- **形态**：铁路拆除后留下的碎石路基，高出周围地面约1.5-2米。两侧长满杂草和灌木
- **长度**：从厂区方向延伸到镇南，约600米
- **宽度**：路基顶面约3米宽，碎石+枕木残迹

**叙事功能：**

| 功能 | 说明 |
|------|------|
| 替代路线 | 不走主街也能南北移动→翻墙/跟踪/躲避时使用 |
| 高于积水线 | D6主街积水时，铁路路基还干着→紧急撤离通道 |
| 纵火犯的路 | D1-D5纵火后纵火犯如何消失？路基=不经过主街的隐蔽通道 |
| 历史层 | 铁路连着工厂的过去→走在路基上="走在这个镇子的动脉上，血已经干了" |
| 见微知著≥3 | 路基碎石上有新鲜脚印（雨后泥地）→有人最近走过→谁？ |

**物理细节：**
- 路基两侧有排水沟（铁路标配），现在长满草
- 从主街到路基：需要穿过居民区后院或空地，没有正式道路
- 北端：靠近厂区围墙，有豁口可以钻过去
- 南端：路基逐渐降低，与镇南地面齐平，消失在杂草中

---

### 3. 老槐树坡（+15m · 地形转折点）

- **位置**：主街中段，十字路口旁
- **形态**：主街在此处有明显的缓坡转折。向北是上坡（约5°），向南是下坡（约3°）
- **标志物**：百年老槐树，树冠遮半条街

**叙事功能：**
- **自然分界线**：坡以上=行政/秩序；坡以下=居民/混乱
- **雨水分水岭**：雨水从老槐树开始向南流→D4起形成可见的地表径流
- **D7洪水线位置**：水涨到老槐树→镇子被"对半切"→镇北镇南物理隔离
- **雾的边界**：站在老槐树下→往下看=白茫茫一片→往上看=模糊但可见
- **预言者奶奶坐在坡顶**："不要左转"→左转=下坡=去便利店方向→她在阻止你走向危险/过去

**视觉效果：**
- 晴天：从老槐树向南看→能看到便利店方向的屋顶、远处河面闪光
- 雾天：从老槐树向南看→雾像河一样在下面流→建筑只露出二楼以上
- D7：从老槐树向南看→水面。向北看→人群

---

### 4. 胡同峡谷（+8m · 雾/声音陷阱）

- **位置**：便利店旁
- **形态**：2米宽死胡同，两侧三层楼高墙壁（约9-10米）
- **高宽比**：约5:1→形成"城市峡谷"效应
- **长度**：约40米，尽头是死胡同（砖墙封死）
- **地面**：水泥地，有裂缝，常年潮湿

**叙事功能：**

| 效应 | 说明 |
|------|------|
| 雾 | 峡谷效应→雾在胡同内极浓，伸手不见五指 |
| 声音 | 窄巷反射→脚步声方向混乱→"你听到声音但不知道从哪来" |
| 风 | 大气压差→胡同口偶有穿堂风→吹散局部雾气→短暂看见某样东西→又消失 |
| 视觉恐惧 | 从胡同口往里看→黑/灰色的深度→像喉咙 |

**D3夜胡同事件的地形支撑：**
- 胡同在便利店旁=低洼+峡谷=双重积雾→"什么都看不见"合理
- 声音反射→施暴者和受害者的声音方向混乱→玩家需要判断
- 穿堂风偶尔吹开雾→短暂看到轮廓→又消失→心理折磨

---

### 5. 河弯内侧沙洲（+2m · 隐蔽会面点）

- **位置**：河弯最内侧，镇子东南方
- **形态**：一小块沙洲/卵石滩，约15×8米
- **遮挡**：河弯弧度+岸边柳树→从镇上主街看不到
- **可达性**：需要从堤坝南端下到河边，沿岸走约200米

**叙事功能：**
- **刘小红偶遇点**：D5河边看到她→坐在沙洲的石头上→一个正在消失的地方坐着一个正在回来的人
- **秘密会面**："不想被人看见"→沙洲被河弯和柳树遮挡→适合私下交谈
- **时间窗口**：D1-D3干燥可达，D4起开始被水淹没→"这个地方只剩几天了"
- **D7完全消失**："你曾经站过的地方现在在水下"→记忆的物理消亡

---

### 6. 排水沟系统（全镇 · 洪水推进指示器）

- **形态**：主街两侧的水泥明沟，宽约30厘米，深约25厘米
- **走向**：沿主街从北向南，最终汇入河边排水口
- **状态**：多年失修，部分堵塞（垃圾/落叶/泥土）

**每日变化：**

| 时间 | 排水沟状态 | 叙事意义 |
|------|-----------|----------|
| D1-D3 | 干的，有垃圾 | 正常小镇景象 |
| D4 | 有水流，速度快 | 暴雨开始→排水系统启动 |
| D5 | 水流汹涌，快要满 | 系统接近极限 |
| D6 | 溢出沟面，路面积水 | 系统失败→人造秩序崩溃 |
| D7 | 完全没入水中 | 已经不存在了 |

**叙事功能：**
- 日常观察指标：玩家经过主街时自然注意到排水沟变化→无需台词的环境叙事
- D6溢出=转折信号：排水沟从"有用"变成"没用"→基础设施的崩溃=社会秩序的崩溃

---

### 7. 西侧丘陵农田（+20m～+30m · 外围缓冲区）

- **位置**：镇子西侧，铁路路基以西
- **形态**：缓坡丘陵+旱地农田，偶有果树
- **可达性**：从十字路口向西走出镇子，约300米
- **功能**：镇子的"边界"——再往西就是农村了

**叙事功能：**
- **国道位置**：国道在丘陵上方通过，连接外部世界
- **修车铺/叔叔家**：靠近镇子西侧→接近丘陵→地势稍高→D6-D7相对安全
- **逃离方向**：如果要离开镇子，向西上丘陵是唯一的旱路→D7这条路还通着
- **远眺视角**：从丘陵回看镇子→能看到盆地全貌→"这个镇子像碗底"

## 四、地形 × 迷雾交互

### 雾浓度分级（按高度）

```
+45m 矸石山顶 ：雾线以上。能见度 >5km。唯一能看到全镇的位置
+30m 厂区台地  ：雾薄。轮廓可辨。烟囱顶部在雾线上方
+20m 镇北行政区：雾中等。3米外可辨人影。能看到主街灯光
+15m 老槐树/坡顶：雾的边界线。往下看=白茫茫。往上看=模糊但可见
+10m 镇南/便利店：雾极浓。1米外看不清人。声音混乱
+ 5m 河滩      ：雾最浓——冷湿空气贴着水面。堤坝石阶消失在白雾中
```

### 特殊地形对雾的影响

| 地形 | 效应 | 游戏意义 |
|------|------|----------|
| 胡同（峡谷） | 雾被困在两墙之间，极浓 | 伸手不见五指，声音方向混乱 |
| 铁路路基（+1.5m） | 比主街略高→雾稍薄 | 比地面多看到一点→隐蔽观察位 |
| 十字路口（开阔） | 风略通→雾偶尔被吹散 | 短暂视野→看到什么又消失 |
| 建筑二楼以上 | 高于地面雾层 | 从窗户看→地面是白色的海 |
| 排水沟 | 水汽上升→沟上方雾更浓 | 沿着水沟走=最差能见度路线 |

### 玩家体验映射

- **李正**（住镇北二楼）：能感知到"南面出事了"但看不见具体情况
- **董点事**（去便利店）：每次都要"走进雾里"——物理上走进过去
- **王少鹏**（中医馆在镇北）：站在权力高地上→对南面一无所知→与他对哥哥的"看不见"平行

## 五、地形 × 洪水交互

### 每日水位与淹没范围

| 日期 | 水位线 | 淹没区域 | 可达性变化 |
|------|--------|----------|-----------|
| D1-D3 | +0m～+3m | 仅河面正常波动 | 全镇正常通行 |
| D4 | +5m以下积水 | 河滩/堤坝湿滑 | 堤坝石阶湿滑，镇内正常 |
| D5 | +8m以下积水 | 便利店地面渗水，修车铺低处进水 | 便利店内行动受限，鞋湿 |
| D6 | +12m以下积水 | 镇南脚踝深，排水沟溢出 | 铁路路基刚好干着=唯一干燥南北通道 |
| D7 | +15m以下积水 | 水到老槐树，便利店膝盖深 | 镇北台地成孤岛，南北隔离 |
| D7+（游戏后） | +25m以下 | 明年水库蓄水，只剩矸石山顶 | 镇子消失 |

## 六、地形 × 纵火可见性交互

### 不同位置看火的效果

| 观察位置 | 看到的火 | 信息量 |
|----------|----------|--------|
| 低处（便利店附近） | 橙色光晕透过雾气，方向模糊，距离不可判断 | 极低——只知道"有火" |
| 主街 | 光晕稍清晰，大致方向可判断 | 低——知道"大概在哪个方向" |
| 铁路路基（+1.5m高） | 高出地面→雾稍薄→比主街多看到一点 | 中低——方向较准 |
| 建筑二楼/三楼 | 从窗户看→高于雾层→能看到光源方向 | 中——方向准确，距离模糊 |
| 职高天台（+10m+四层） | 视角高→雾薄处能看到火焰实体 | 中高——能判断方位和大概位置 |
| 矸石山顶（+45m） | 最佳位置。雾线以上→直视火源 | 最高——精确位置+周围人影移动 |

### "去哪里看火"=玩家选择

- **冲向火源**：风险最高，但可能撞见纵火犯→坚毅检定
- **爬上高处**：消耗时间但信息最多→时间成本
- **待在原地判断方向**：折中方案→见微知著检定
- **叫人一起去**：安全但慢→可能错过现场

## 七、地形 × 声音传播规则

### 基本规则

| 条件 | 效果 | 原因 |
|------|------|------|
| 高→低传播 | 远距离可闻 | 坡地+冷空气层=声波折射向下 |
| 低→高传播 | 距离衰减快 | 声波向上散逸 |
| 胡同内 | 方向混乱 | 多次反射→无法定位声源 |
| 雾天 | 声音传更远 | 湿空气密度大→声波衰减慢 |
| 雾天+胡同 | 最差情况 | 传得远+方向乱=听到但找不到 |
| 河边 | 水声遮盖 | D4起河水声增大→掩盖其他声音 |

### 具体示例

- **修车铺的敲打声**（+13m）→向南传到便利店区（+10m）：可闻。反过来不行
- **便利店区的呼喊**（+10m）→向北传到派出所（+20m）：雾天几乎不可闻
- **胡同里的尖叫**→胡同口以外：声音传出来了，但方向判断需要见微知著检定
- **D7堤坝溃水声**→全镇可闻：低频轰鸣→不需要检定就能感知到"大事不好"

## 八、地形 × 角色移动路线

### 四条南北路线

```
西                                                 东

丘陵小路    铁路路基    主街      河边小路
  │           │         │          │
  │隐蔽/泥路  │隐蔽/碎石  │公开/水泥   │隐蔽/土路
  │           │         │          │
  ↓           ↓         ↓          ↓
通向国道    南北穿越    正常通行    沿河走
```

| 路线 | 特点 | 适用场景 |
|------|------|----------|
| **主街** | 公开、有路灯（部分）、最快 | 正常移动、白天活动 |
| **铁路路基** | 隐蔽、高于积水线、有脚印线索 | 跟踪、躲避、D6紧急通道 |
| **河边小路** | 隐蔽、靠近水面、D5起危险 | 去沙洲、观察河面、D1-D4散步 |
| **丘陵小路** | 最隐蔽、泥路、费时 | 离镇/回镇的替代路线、D7逃离 |

### 东西向通道

- **十字路口**：唯一正式的东西向道路。东通河边（堤坝），西通丘陵（国道方向）
- **居民区后院**：非正式通道，需穿过私人领地。从主街到铁路路基的连接方式
- **胡同**：东西向死胡同（便利店旁），不通向任何地方→陷阱地形

### 纵火犯的可能路线

根据地形分析，WYP纵火后最可能的逃离路线：
1. 从纵火现场→穿居民区后院→上铁路路基→向北撤离→消失在厂区方向
2. 全程不经过主街→不经过任何有灯光的地方→只有路基碎石上的脚印（雨后）
